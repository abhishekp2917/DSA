Question Link : https://www.geeksforgeeks.org/problems/flattening-a-linked-list/1

* Problem:
  Flatten a linked structure where each node has a next pointer connecting vertical lists and a bottom pointer connecting nodes within each sorted vertical list.

* Key observation:
  This is equivalent to merging multiple sorted linked lists.

* Initially add the head of every vertical list to a min-heap because these are the smallest currently available candidates from each list.

* The heap always contains at most one candidate from each vertical list.

* Remove the smallest node from the heap and append it to the flattened list using bottom.

* After removing a node, its bottom node becomes the next candidate from the same vertical list, so add it to the heap.

* The next pointers are not used in the final flattened list; the result is connected entirely through bottom pointers.

* A dummy node simplifies construction because every selected node can be appended using ptr.bottom.

* Time Complexity: O(N log K)

* Space Complexity: O(K)
