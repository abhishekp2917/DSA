Question Link : https://www.geeksforgeeks.org/problems/reverse-a-linked-list/1

* Problem:
  Reverse a singly linked list in-place.

* Key observation:
  Reverse each next pointer one node at a time while maintaining access to the remaining list.

* prev represents the already reversed portion, while curr represents the current node being processed.

* Before changing curr.next, store it in next because changing the pointer would otherwise lose the remaining list.

* Set curr.next = prev to reverse the current node's pointer.

* Move prev = curr because the current node is now the first node of the reversed portion.

* Move curr = next to continue processing the unreversed portion.

* Initially prev = null because the original head becomes the last node and must point to null after reversal.

* When curr becomes null, every pointer has been reversed and prev points to the new head.

* Time Complexity:
  O(n)

* Space Complexity:
  O(1)
