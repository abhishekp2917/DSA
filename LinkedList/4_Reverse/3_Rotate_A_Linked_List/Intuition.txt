Question Link : https://www.geeksforgeeks.org/problems/rotate-a-linked-list/1

* Problem:
  Rotate the linked list by k positions to the left.

* Key observation:
  Split the list after the k-th node and move the first part to the end.

* Example:
  1 -> 2 -> 3 -> 4 -> 5, k = 2

  Split:
  1 -> 2

  3 -> 4 -> 5

  Connect:
  3 -> 4 -> 5 -> 1 -> 2

* tail is moved to the k-th node because that is where the list must be split.

* firstHead is moved to the node immediately after the k-th node because that node becomes the new head.

* If firstHead == null, k equals the list length, so rotating produces the original list.

* tail.next = null breaks the original list into two independent parts.

* The tail of the second part is then connected to the original head.

* secondHead stores the original head because that first part needs to be appended after the second part.

* Time Complexity:
  O(n), because the list is traversed to find the split point and then the tail of the second part.

* Space Complexity:
  O(1), because only a constant number of pointers are used.
