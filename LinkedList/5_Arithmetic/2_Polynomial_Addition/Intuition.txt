Question Link : https://www.geeksforgeeks.org/problems/polynomial-addition/1

* Problem:
  Add two polynomials represented by linked lists sorted by decreasing power.

* Key observation:
  Since both lists are sorted by power, the problem is equivalent to merging two sorted linked lists.

* If p1.pow > p2.pow:
  The p1 term must appear next because it has the larger power.

* If p2.pow > p1.pow:
  The p2 term must appear next for the same reason.

* If p1.pow == p2.pow:
  Both terms are like terms, so their coefficients must be added.

* Example:
  5x^3 + 4x^2 + 2
  3x^3 + 7x + 1

  Equal powers:
  5x^3 + 3x^3 = 8x^3

  Result:
  8x^3 + 4x^2 + 7x + 3

* We reuse existing nodes instead of creating new nodes for the result, except for the dummy node.

* curr.next = null after selecting a node ensures that the selected node does not retain an unwanted connection to its original list.

* Once either polynomial is exhausted, the remaining nodes of the other polynomial can be appended directly because they are already sorted.

* Dummy node:
  Makes result construction uniform and avoids separately handling the first term.

* Time Complexity:
  O(n + m)

* Space Complexity:
  O(1)
