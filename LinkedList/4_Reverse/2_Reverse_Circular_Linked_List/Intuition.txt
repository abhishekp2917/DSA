* Problem:
  Reverse a circular doubly linked list.

* Key observation:
  Since the list is circular, we cannot use curr != null as the stopping condition.

* Traverse until curr becomes head again because returning to head means every node has been processed.

* For a doubly linked list, reversing only next pointers is insufficient because prev pointers would still point in the original direction.

* Therefore, for every node, swap its next and prev pointers.

* Save the original curr.next before swapping because it is needed to move to the next unprocessed node.

* After reversing all nodes, the original tail becomes the new head.

* Since head.prev points to the original tail after the reversal, return head.prev.

* Time Complexity:
  O(n)

* Space Complexity:
  O(1)
