* Problem:
  Given two sorted linked lists, return their intersection as a new linked list.

* Key observation:
  Since both lists are sorted, we can use two pointers and compare their current values.

* If head1.data == head2.data:
  The value exists in both lists, so add it to the result and move both pointers forward.

* If head1.data > head2.data:
  head2 contains the smaller value, so move head2 forward because it can never match the larger head1 value at its current position.

* If head1.data < head2.data:
  head1 contains the smaller value, so move head1 forward for the same reason.

* Why is it safe to discard the smaller value?
  Because the lists are sorted, every future value in that list is greater than or equal to the current smaller value.

* Dummy node:
  ans simplifies result-list construction because every matched value can be appended using curr.next without separately handling the first node.

* The loop stops when either list is exhausted because no further intersection is possible.

* Time Complexity:
  O(n + m), because each pointer moves only forward through its respective list.

* Space Complexity:
  O(k), where k is the number of elements in the intersection, because a new result list is created.
