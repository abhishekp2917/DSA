Question Link : https://www.geeksforgeeks.org/problems/reverse-a-linked-list-in-groups-of-given-size/1

* Problem:
  Reverse a linked list in groups of k nodes.

* Key observation:
  Reverse one group of k nodes, then recursively reverse the remaining list.

* During the first loop, prev becomes the head of the reversed current group and curr becomes the first node of the next group.

* next must be saved before changing curr.next because otherwise the remaining list would be lost.

* After reversing the group, the original head becomes the last node of that group.

* Therefore, connect head.next to the result of recursively reversing the remaining nodes.

* If fewer than k nodes remain, the loop reverses those remaining nodes as well.

* The base condition for recursion is implicitly handled because when next == null there is no remaining group to process.

* Example:
  1 -> 2 -> 3 -> 4 -> 5, k = 2

  First group:
  1 -> 2 becomes 2 -> 1

  Remaining:
  3 -> 4 -> 5 becomes 4 -> 3 -> 5

  Result:
  2 -> 1 -> 4 -> 3 -> 5

* Time Complexity:
  O(n), because every node is processed exactly once.

* Space Complexity:
  O(n/k) recursion stack, because one recursive call is made for each group.
