* Problem:
  Split a circular linked list into two circular linked lists of approximately equal size.

* Key observation:
  Use the slow-fast pointer technique to find the midpoint without knowing the length of the circular list.

* slow moves one node at a time, while fast moves two nodes at a time.

* Because the list is circular, fast stops when it reaches head or when fast.next reaches head.

* After the loop:
  slow points to the last node of the first half.

* Therefore:
  head2 = slow.next gives the first node of the second half.

* First half:
  Set slow.next = head to close the first half into a circular list.

* Second half:
  Traverse from head2 until reaching the original head, because the last node of the second half still points to head.

* Then set curr.next = head2 to close the second half into its own circular list.

* Important:
  No new nodes are created; only next pointers are modified.

* Time Complexity:
  O(n), because finding the midpoint and finding the second-half tail together visit O(n) nodes.

* Space Complexity:
  O(1), because only a few pointers are used.
