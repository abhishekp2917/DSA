Question Link : https://www.geeksforgeeks.org/problems/linked-list-in-zig-zag-fashion/1

* Problem:
  Rearrange the linked list so that the values follow the pattern a < b > c < d > e ...

* Key observation:
  Only adjacent pairs need to be checked because each position has a required relation with its immediate neighbour.

* shouldBeLessThan tells whether the current pair must satisfy curr < next or curr > next.

* If the required relation is violated, swap the two adjacent nodes.

* If the relation is already correct, simply move to the next pair.

* A dummy node is used so that swapping the original head works exactly like swapping any other pair.

* After swapping, the pointers are updated differently because the two nodes have changed positions.

* swap() changes only three links: previous -> second node -> first node -> remaining list.

* The relation is toggled after every pair because the required pattern alternates between < and >.

* Time Complexity: O(n)
* Space Complexity: O(1)
