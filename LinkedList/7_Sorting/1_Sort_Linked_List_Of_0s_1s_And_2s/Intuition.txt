* Problem:
  Segregate a linked list containing only 0s, 1s and 2s so that all 0s come first, followed by 1s and then 2s.

* Key observation:
  Since there are only three possible values, maintain three separate linked lists instead of sorting the nodes.

* Traverse the original list once and append each node to the corresponding 0s, 1s or 2s list.

* Dummy nodes simplify appending because every list has an initial node.

* Detach each selected node by setting its next pointer to null so that it does not retain its old connection.

* Finally connect the three lists in the order 0s -> 1s -> 2s.

* If the 1s list is empty, connect the 0s list directly to the 2s list.

* The original nodes are reused; no new nodes are created apart from the dummy nodes.

* Time Complexity: O(n)

* Space Complexity: O(1)
