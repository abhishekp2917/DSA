Question Link : https://www.geeksforgeeks.org/problems/add-two-numbers-represented-by-linked-lists/1

* Problem:
  Add two numbers represented by linked lists where each node contains one digit.

* Key observation:
  Normal addition starts from the least significant digit, but the linked lists store the most significant digit first.

* Therefore, reverse both lists so that addition can be performed from left to right.

* At every position, add digit1 + digit2 + carry and create one result node.

* If one list is shorter, treat its missing digits as 0.

* tempSum % 10 gives the current digit, while tempSum / 10 gives the carry for the next position.

* The loop also checks carry != 0 because an extra digit may be required after both lists are exhausted.

* Example:
  9 -> 9
  1

  Reverse:
  9 -> 9
  1

  Addition:
  9 + 1 = 10 → digit 0, carry 1
  9 + 0 + 1 = 10 → digit 0, carry 1
  Final carry = 1

  Result after reversing:
  1 -> 0 -> 0

* A dummy node is used so that every result digit can simply be appended using ptr3.next.

* Finally, reverse the result because the digits were generated from least significant to most significant.

* Time Complexity:
  O(n + m)

* Space Complexity:
  O(n + m)
