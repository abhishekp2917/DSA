Question Link : https://www.geeksforgeeks.org/problems/quick-sort-on-linked-list/1

* Problem:
  Sort a singly linked list using the QuickSort partitioning idea.

* Key observation:
  Choose a pivot and partition the list into values smaller than the pivot, equal to the pivot, and greater than the pivot.

* The equal-to-pivot partition is already in its correct relative position, so only the smaller and greater partitions need recursive sorting.

* The first node is used as the pivot value, so no separate pivot node needs to be created.

* splitNodesAroundThreshold() physically moves existing nodes into three lists instead of creating new data nodes.

* prev is required to remove curr from the original list because changing prev.next skips curr.

* Each moved node is detached with ptr.next = null so that it does not retain its old connection.

* After recursively sorting the smaller and greater partitions, concatenate them as smaller -> equal -> greater.

* getLastNode() is needed to connect the next partition after the tail of the current partition.

* Dummy nodes simplify both partition construction and final list concatenation.

* Time Complexity: O(n²) worst case, O(n log n) average case

* Space Complexity: O(n) worst case recursion stack + partition lists
