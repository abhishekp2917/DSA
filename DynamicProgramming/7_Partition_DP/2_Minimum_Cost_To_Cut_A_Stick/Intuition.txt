Question Link : https://leetcode.com/problems/minimum-cost-to-cut-a-stick/description/

*   We need to perform every cut exactly once.

*   Cutting a stick costs its current length.

*   The order of cuts changes the total cost.

*   After making one cut, the stick splits into two independent pieces.

*   Future cuts on one piece never affect the other piece.

*   Therefore, the first cut completely determines the remaining subproblems.

*   Sort the cuts first.

*   Sorting allows every interval of cuts to represent one continuous stick segment.

*   DP State:

        dp[start][end]

    stores the minimum cost to perform all cuts from cuts[start] to cuts[end].

*   Base case:

        start > end

*   No cuts remain.

*   Therefore the required cost is 0.

*   Try every cut inside the interval as the first cut.

*   The current cutting cost equals the length of the stick before making that cut.

*   The stick boundaries are determined by the nearest cuts outside the current interval.

*   Total cost for choosing one cut first is:

        Current stick length

        +

        Left subproblem cost

        +

        Right subproblem cost

*   Transition:

        dp[start][end]

        =

        minimum over every first cut

        of

        stick length

        +

        left cost

        +

        right cost

*   Memoization computes every interval only once.

*   Tabulation builds smaller intervals before larger intervals.

*   Number of DP states:

        O(m²)

*   Every state tries every possible first cut.

*   Time Complexity:
        O(m³)

*   Space Complexity:
        O(m²)
