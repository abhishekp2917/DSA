Question Link : https://www.geeksforgeeks.org/problems/remove-loop-in-linked-list/1

* Problem:
  Detect and remove a loop from a linked list without changing the nodes.

* Key observation:
  First detect the cycle using Floyd's slow-fast pointer technique.

* slow moves one step while fast moves two steps.

* If fast reaches null, there is no cycle and we return immediately.

* If slow and fast meet, a cycle exists.

* To find the first node of the cycle:
  Reset slow to head and move both slow and fast one step at a time.

* Why does this find the cycle start?
  The distance from head to the cycle start equals the appropriate remaining distance from the meeting point around the cycle.

* Once slow == fast, both pointers are at the first node of the cycle.

* The cycle cannot simply be removed by setting slow.next = null because slow is the cycle's first node, not necessarily its last node.

* Therefore, keep slow at the cycle start and move fast around the cycle until fast.next == slow.

* fast is then the last node of the cycle.

* Set fast.next = null to break the cycle while preserving the entire linked list.

* Time Complexity:
  O(n)
  
* Space Complexity:
  O(1)
