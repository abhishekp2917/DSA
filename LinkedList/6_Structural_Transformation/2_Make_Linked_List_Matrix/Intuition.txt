Question Link : https://www.geeksforgeeks.org/problems/linked-list-matrix/1

* Problem:
  Convert a 2D array into a linked matrix where each node has right and down pointers.

* Key observation:
  Create one Node for every array element and connect each node to its immediate right and bottom neighbours.

* matrix[i][j] stores the Node corresponding to arr[i][j].

* An extra row and column are created so that boundary nodes can simply point to null without requiring separate boundary checks.

* right points to matrix[i][j+1], representing the next column.

* down points to matrix[i+1][j], representing the next row.

* matrix[0][0] is returned as the entry point to the complete linked matrix.

* Time Complexity: O(n²)

* Space Complexity: O(n²)
