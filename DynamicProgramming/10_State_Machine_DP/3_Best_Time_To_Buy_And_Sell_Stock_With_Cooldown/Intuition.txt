Question Link : https://leetcode.com/problems/best-time-to-buy-and-sell-stock-with-cooldown/description/

*   We may perform unlimited transactions.

*   After selling a stock, we must wait one full day before buying again.

*   Therefore, besides the current day and holding state, the cooldown rule changes only the BUY transition.

*   DP State:

        dp[day][hasStock]

*   If we currently own a stock, we have two choices:

        Sell today

        OR

        Continue holding.

*   Selling immediately starts the cooldown period, so the next valid trading day becomes day + 2.

*   If we do not own a stock, we again have two choices:

        Buy today

        OR

        Skip today.

*   Buying today is allowed only if yesterday was not a selling day.

*   In the tabulation solution, this is handled by buying from:

        dp[day-2][0]

    instead of

        dp[day-1][0]

*   This automatically enforces the one-day cooldown after every sale.

*   Memoization computes every (day, state) only once.

*   Tabulation processes the days from left to right while respecting the cooldown dependency.

*   The final answer is dp[n][0] because any stock still being held has not yet been converted into realised profit.

*   Time Complexity:
        O(n)

*   Space Complexity:
        O(n)
