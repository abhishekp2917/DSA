Question Link : https://www.geeksforgeeks.org/problems/subtraction-in-linked-list/1

* Problem:
  Subtract two non-negative numbers represented by linked lists, where each node stores one digit.

* Key observation:
  Normal subtraction starts from the least significant digit, so reverse both lists before performing the subtraction.

* First remove leading zeroes because they do not affect the numerical value and would make length-based comparison incorrect.

* compare() determines which number is larger so that we always calculate larger - smaller and avoid negative final results.

* If the numbers have different lengths, the number with more digits is larger.

* If both have the same length, compare digits from left to right; the first different digit determines which number is larger.

* After reversing, the first nodes contain the least significant digits, so corresponding digits can be subtracted directly.

* The first subtraction pass calculates raw digit differences without immediately handling borrowing.

* Example:
  100 - 99

  Raw subtraction from right to left:
  0 - 9 = -9
  0 - 9 = -9
  1 - 0 = 1

* Borrow propagation fixes negative digits from right to left:
  -9 becomes 1 after borrowing 1 from the next digit, and the next digit decreases by 1.

* After all borrows are resolved, reverse the result again to restore the normal digit order.

* Leading zeroes may appear after subtraction, such as 001 for 100 - 99, so removeLeadingZeroes() is called before returning.

* If all digits are removed, the result was exactly zero, so return a single node containing 0.

* Time Complexity:
  O(n + m)

* Space Complexity:
  O(1)
